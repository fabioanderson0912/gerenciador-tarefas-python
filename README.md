# Gerenciador de Tarefas em Python (CLI)

Aplicação de linha de comando (CLI) desenvolvida em **Python** para organizar tarefas diárias com persistência de dados em **JSON**.

## Funcionalidades

- Cadastrar novas tarefas
- Listar tarefas cadastradas
- Marcar tarefas como concluídas
- Remover tarefas
- Guardar e carregar dados automaticamente em ficheiro `JSON`

## Tecnologias utilizadas

- **Python 3**
- **JSON** (persistência local de dados)
- **Git & GitHub**

## Como executar o projeto

1. Clona o repositório:
   ```bash
   git clone [https://github.com/fabioanderson0912/gerenciador-tarefas-python.git](https://github.com/fabioanderson0912/gerenciador-tarefas-python.git)
   Entra na pasta do projeto: cd gerenciador-tarefas-python
   Executa o ficheiro principal em Python: python main.py
